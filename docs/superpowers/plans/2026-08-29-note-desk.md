# Note Desk (Unified Note + UI Polish) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace separate Transcript/Outputs destinations with one Note view (transcript + **summary** side by side), where the user picks a **summary format** then generates; apply Option A UI polish.

**Architecture:** Keep `RecordingSession` as the source of truth. Add `NoteView` with a wide `HSplitView` (transcript | summary) and a narrow segmented fallback. Summary pane: format picker (`NoteTemplate` display names), provider, **Generate summary**. Slim sidebar to Record / Library / Favorites / Settings. UI copy says “summary” / “format”, never “output”. On-disk `outputs/` paths unchanged.

**Tech Stack:** SwiftUI (macOS 26+), MuffinCore `RecordingSession`, existing `DocumentPage` / panel components.

**Spec:** `docs/superpowers/specs/2026-08-29-note-desk-design.md`

## Global Constraints

- macOS 26+, light editorial UI, system fonts only (New York / SF)
- No emdash in user-facing copy; no purple/glow/dark-mode drift
- Do not change on-disk layout (`transcript.md`, `outputs/<template>.md`)
- Do not break menu bar, Hold Fn, clipboard-on-stop, or Accessibility silent-check behavior
- Prefer Option A polish unless the human overrides to B/C in the spec
